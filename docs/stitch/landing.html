Engine & Pipeline

How it works

Single source of truth color tokens compiled deterministically across distinct formatting targets.

01 / SOURCE

One palette.json

All colors, surfaces, contrast bounds, and semantic ANSI mappings reside in a central schema-validated palette.json file.

02 / COMPILATION

Generated ports

Running make build invokes the Mustache template engine to emit pure native configurations for Ghostty, VS Code, bat, GTK and more.

03 / VALIDATION

Tested & verified

Automated CI runs WCAG 2.1 AA/AAA contrast checks and visual regression tests to verify absolute zero color drift between ports.

Quickstart

Installation

Simple one-line configurations for your active shell and workspace tools.

Append Terminal Noir directly into your Ghostty config:
curl -fsSL https://terminalnoir.dev/ports/ghostty/terminal-noir.conf >> ~/.config/ghostty/config
Tip: Reload Ghostty with Cmd+Shift+, to activate instantly.
Install from the official VS Code CLI extension registry:
code --install-extension terminal-noir.terminal-noir-theme
Set "workbench.colorTheme": "Terminal Noir" in your settings.json.
Fetch theme and rebuild bat cache:
mkdir -p "$(bat --config-dir)/themes" && curl -fsSL https://terminalnoir.dev/ports/bat/terminal-noir.tmTheme -o "$(bat --config-dir)/themes/terminal-noir.tmTheme" && bat cache --build
Configure via export BAT_THEME="terminal-noir" in your shell dotfiles.
Export ANSI high-contrast colors in your .zshrc / .bashrc:
export FZF_DEFAULT_OPTS="--color=bg+:#18181B,bg:#0B0B0C,spinner:#F5A623,hl:#FACF9E --color=fg:#F4F4F5,header:#79C0FF,info:#34D399,pointer:#F5A623 --color=marker:#34D399,fg+:#F4F4F5,prompt:#F5A623,hl+:#F5A623"
Tested across fzf v0.48+ with full border rendering.

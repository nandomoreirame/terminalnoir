# Terminal Noir for btop

A [btop](https://github.com/aristocratos/btop) color theme: amber titles, outline boxes, and load gradients that run from emerald through cream to pink.

## Install

```sh
mkdir -p ~/.config/btop/themes
cp terminal-noir.theme ~/.config/btop/themes/
```

Then pick it in btop's options (Esc > Options > Color theme), or set `color_theme = "terminal-noir"` in `~/.config/btop/btop.conf`.

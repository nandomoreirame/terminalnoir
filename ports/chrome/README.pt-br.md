# Terminal Noir para Google Chrome

Um tema para o navegador: moldura, abas, barra de ferramentas, barra de endereço e página de nova aba. Os temas do Chrome não têm variante clara.

## Instalação

1. Abra `chrome://extensions` e ative o Modo do desenvolvedor.
2. Clique em "Carregar sem compactação" e escolha esta pasta `ports/chrome`.

O tema continua ativo depois de reiniciar o navegador. Quando o `make build` mudar o tema, clique em recarregar no card da extensão.

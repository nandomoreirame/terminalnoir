# Terminal Noir para Ghostty

Temas para o [Ghostty](https://ghostty.org), nas variantes escura e clara.

## Instalação

```sh
mkdir -p ~/.config/ghostty/themes
cp terminal-noir-dark terminal-noir-light ~/.config/ghostty/themes/
```

Em `~/.config/ghostty/config`, siga a preferência clara ou escura do sistema:

```
theme = light:terminal-noir-light,dark:terminal-noir-dark
```

Janelas novas já abrem com o tema; recarregue as abertas com `Ctrl+Shift+,`.

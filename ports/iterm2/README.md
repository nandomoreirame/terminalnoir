# Terminal Noir for iTerm2

[iTerm2](https://iterm2.com) color presets for dark and light: `Terminal Noir.itermcolors` and `Terminal Noir Paper.itermcolors`.

![Terminal Noir for iTerm2](../../assets/screenshots/iterm2.png)

## Install

Import both presets from the terminal:

```sh
open "Terminal Noir.itermcolors" "Terminal Noir Paper.itermcolors"
```

Or go to **Settings > Profiles > Colors > Color Presets... > Import...** and pick the two files. Then select **Terminal Noir** in the same menu.

To follow the macOS appearance, check **Use different colors for Light and Dark mode** in the Colors tab, then load **Terminal Noir** while editing the Dark side and **Terminal Noir Paper** while editing the Light side.

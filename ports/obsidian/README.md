# Terminal Noir for Obsidian

An Obsidian theme for dark mode: near-black panes, amber links and accent, and code blocks in the same colors as the editor ports.

## Install

1. Copy the `Terminal Noir` folder to `<your vault>/.obsidian/themes/`.
2. In Obsidian: Settings > Appearance, set Base color scheme to Dark, then pick Terminal Noir under Themes.

The folder is a standard community theme (`manifest.json` + `theme.css`), so it can also be loaded from a fork of [obsidian-releases](https://github.com/obsidianmd/obsidian-releases) once published.

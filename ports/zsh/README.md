# Terminal Noir for zsh

Command-line colors for [zsh](https://www.zsh.org): [zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting) styles with blue commands, amber keywords and emerald strings, plus a faint [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions) hint. `terminal-noir.zsh` is the dark variant and `terminal-noir-paper.zsh` the light one.

![Terminal Noir for zsh](../../assets/screenshots/zsh.png)

## Install

Source one of the files from your `.zshrc`:

```sh
source /path/to/terminalnoir/ports/zsh/terminal-noir.zsh
```

The order relative to the plugins does not matter. The colors are 24-bit hex, so your terminal needs true color (Ghostty, iTerm2, kitty, WezTerm and most modern terminals have it).
